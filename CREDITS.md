# Credits

xCloud Dotfiles is a rebranded personal fork of
[**ML4W OS - Dotfiles for Hyprland**](https://github.com/mylinuxforwork/dotfiles)
by **Stephan Raabe** ([@mylinuxforwork](https://github.com/mylinuxforwork)).

The overwhelming majority of the configuration, scripts, and design decisions in this
repository originate from that upstream project. This fork strips ML4W-specific branding
and retargets a few defaults (theme colors, cursor, wallpaper source) for personal use —
it does not represent original design work beyond that.

Many individual files also carry their own original per-file authorship comments

have been left untouched.

The companion wallpaper collection was similarly forked from
[mylinuxforwork/wallpaper](https://github.com/mylinuxforwork/wallpaper) into
[xc0sh/wallpapers](https://github.com/xc0sh/wallpapers) — see that repository's own
`NOTICE.md` for its GPL-2.0 attribution.
